# Modern command compatibility

This is a finite description of this source candidate. Use `an` for Anthracite and `gt` for Graphite. It is not a claim that every Graphite option, service or installed release behaves identically. [The command reference](./DOCUMENTATION.md) describes the actual flags.

The [0.4.0 parity register](./docs/graphite-parity.md) is the current index of shipped work, remaining interfaces, deliberate differences and unanswered comparisons against the pinned Graphite 1.8.6 reference. Historical specifications and acceptance records keep their original source/version boundaries.

The evidence below consists of public CLI subprocess tests with real temporary Git repositories, independent state observations and controlled external tools. Native acceptance runs the same scenario identities against a separately compiled candidate. Local PR adapters prove local workflow behavior, not GitHub or Graphite service acceptance. Build identities, measured counts, final review and publication receipts belong to the implementation delivery report; source test links alone do not assert that a particular build passed.

| Graphite token transport | Unsupported; rejected explicitly. Existing `an auth` uses `gh`, not Graphite activation. |

| Graphite AI/browser/backend services and hosted merge queue | Outside the parity goal, not a later implementation phase. Independent local option gaps such as into/reset-author are separate from those services. |
| Quiet interactive-rebase behavior | Deliberate Anthracite choice: quiet blocks the editor before mutation. The investigated Graphite invocation opened an editor. |
| `ss` boolean overrides | Explicit fixed contract: later stack booleans replace its true default. Graphite backend scope with these combinations was not live measured. |
| Raw Git prefixes | Existing direct cwd selection retained; other unsupported prefix positions may fail. No automatic branch fallback and no new generic Git-prefix grammar. |

## Frozen branch compatibility

This contract covers the flat commands registered in this candidate. Old test directory names such as branch, commit and upstack are regression locations; they do not register removed public namespaces. Freeze and unfreeze have one optional literal local tracked branch selector and no short aliases. Root i means info, while repo i remains init; root s means submit, while repo s remains sync. Log s/l remain short/long.

| Public routes                                                                            | Frozen policy                                                                                                                                                                                                                                                                                               |
| ---------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| freeze / unfreeze                                                                        | Freeze selected branch plus tracked downstack before trunk; unfreeze selected branch plus every tracked descendant. Invalid scopes and trunk refuse before any status writes. Status is shared across linked worktrees; setting status does not stage, checkout or invoke hooks.                            |
| modify/m, modify --interactive-rebase, edit/e, squash/sq, split/sp, pop                  | Refuse a frozen content source, including identity/no-op requests. Force/no-verify do not thaw status.                                                                                                                                                                                                      |
| move --onto/-o --source/-s --only, fold / fold --stack, reorder/ro, create/c --insert/-i | Refuse frozen mandatory parent-change, contributor, survivor or replay participants before effects. Frozen read-only destination/prefix/off-chain anchors remain allowed.                                                                                                                                   |
| create/c --onto/-o, editable descendants                                                 | New ordinary children stay editable above frozen parents; existing editable descendants may make real commits.                                                                                                                                                                                              |
| restack/r, implicit generic restacks                                                     | Explain frozen skips, retain their tips, parents and recorded bases, and replay editable descendants against actual remaining tips. A stale frozen anchor stays stale. Structural mandatory replay is never weakened into a generic skip.                                                                   |
| rename/rn, track/tr, untrack/ut/utr                                                      | Preserve identity/status/PR metadata on rename and existing status on retrack. Removing tracking removes its own status; retained descendants keep stored protection. Genuinely new local tracking is editable.                                                                                             |
| delete/dl, sync cleanup                                                                  | A frozen target/leaf may be removed under existing rules. Mandatory frozen survivors block local deletion; cleanup skips blocked candidates and dependent ancestors, while independent safe work may progress.                                                                                              |
| init, repo init / repo i                                                                 | Ordinary rebuild preserves protection. Explicit full reset removes affected tracking/status. A frozen new trunk refuses before config changes unless that reset is selected.                                                                                                                                |
| get/g --unfrozen/-U                                                                      | Each new import is editable only with an explicit true override or trustworthy own PR-author/current-gh-login match. Other/unknown/error identities conservatively freeze. Explicit false retains that default. Existing stored status always wins over force/U or changed authorship.                      |
| get/g existing branches                                                                  | No-op/FF and explicitly permitted remote takeover retain status. Frozen divergence never performs a local rebase; choose existing remote overwrite or unfreeze. Necessary fetch refs/objects can already have advanced before a later refusal.                                                              |
| sync, repo sync / repo s                                                                 | Existing trunk, PR-information, cleanup and optional-restack scope. Feature heads are not generally refreshed; use get. No added Graphite-version synchronization or new sync flags.                                                                                                                        |
| submit/s/ss, including dry-run                                                           | Skip frozen heads before push/PR writes/editors/reviewer/draft/publish preparation. Editable descendants use the frozen base under existing remote-match checks. All-frozen selection succeeds with explanation; dry-run has the same filtering.                                                            |
| continue/cont --all                                                                      | Recheck actual active replay and remaining mandatory participants before staging/next effects. Saved get import decisions survive process restart; later generic frozen items may skip. Explicit unfreeze permits recovery; raw rebase --abort keeps its bounded Git scope.                                 |
| info/i, log/l, log short / log s / ls                                                    | Show literal (frozen) beside protected identities. Classic and Git-based log long / log l / ll keep their previous rendering. Navigation and relation/patch/diff/stat inspection remain available.                                                                                                          |
| help/completion, cwd, quiet / --no-interactive                                           | Existing global interaction policy, local branch selectors and get -U are public. Quiet suppresses ordinary success/skip output and retains errors. Existing dirty/ignored/index/worktree safeguards remain authoritative after unfreeze. Private commit/push bridges stay out of help and root completion. |
| direct Git, raw Git, internal debug metadata editors                                     | Outside enforcement. For example a direct Git commit or raw an reset can change a frozen branch; status is not an operating-system lock. Managed checkpoints do not promise general cross-process security, atomic rollback or universal undo.                                                              |

The approved research measured Graphite **1.8.6** cascade and lifecycle behavior: downstack freeze, upstack unfreeze, generic restack skips, metadata-only track/rename, permitted delete/untrack and editable ordinary children. Anthracite deliberately excludes the observed unfreeze-trunk bug. It also deliberately refuses delete/insert before mandatory frozen survivor parent changes, where those Graphite fixtures changed the parent and skipped replay. Markers are limited to Anthracite's own default/short renderers, and the limited sync scope remains a named parity gap. Author defaults and remote handling include explicit Anthracite decisions and official-documentation research; they were not established through a live Graphite service session. The [frozen research and original observation index](https://github.com/danielbaars/dinky-misc/blob/0b234895e0ce96960dd9054e4419bc64329165c4/research/charcoal-freeze-unfreeze-spec-research-2026-10-25.md) retain that provenance.

Public feature suites use built CLI subprocesses, real temporary Git/bare/worktrees and independent commits/parents/trees/index/files/recovery observations. External gh, editors and hooks are controlled replay. This proves bounded local behavior, without live GitHub/Graphite accounts, authentication, PR services, global installation, source/upstream push or release acceptance. Bash/zsh smoke runs without startup files; Fish receives generated-content and public-query checks, without claiming full interactive Fish or platform certification.

The original freeze/unfreeze specification set a delivery gate reconciling **100 stories, 32 policy rows and 15 decisions**, with complete local/native selections, Counter equality and independent reviews on a pinned source. Those are historical delivery requirements, not new 0.4.0 execution counts or instructions to run the full matrix for documentation or npm-only releases. Counts, hashes and failed/red/partial qualifications remain attached to their original delivery evidence. The prior modern-command observations likewise remain historical evidence; this source document does not claim fresh execution or complete Graphite parity.

## Absorb compatibility

`absorb`/`ab` supports preview (`-d`), forced noninteractive application (`-f`), tracked-only all (`-a`) and real-terminal patch selection (`-p`). Ordinary text hunks can reach distinct earlier/interior commits while retaining authors, full messages, branch names and PR metadata. Every mandatory descendant and fan-out arm replays. Unsupported staged entries and unassignable hunks stay staged and are reported; trunk and frozen candidate commits are excluded. Frozen or occupied mandatory participants and known source/recovery/file blockers refuse before staging or rewriting. See [the command reference](./DOCUMENTATION.md#absorb-alias-ab) and [approved contract](./docs/specs/absorb.md).

Unchanged binary entries and Unicode symlinks replay losslessly. Stable gitlinks retain their superproject entry without reading their commit object as a blob or touching nested files, HEAD or index, including dirty initialized modules and absent uninitialized paths. Recursive submodule checkout is disabled only for absorb's owned Git operations. All construction/replay trees must keep the same gitlink paths/pointers; actual pointer/add/delete/type transitions and physical collisions refuse early. Non-UTF8 physical link targets and unsupported byte conversions/index states refuse before staging. This bounded behavior does not initialize, fetch or update submodules. With `--all`, real tracked-only Git staging can project deletion of a physically absent module; that gitlink transition is refused before real staging. Use plain absorb for unrelated staged text while keeping the module absent.

A genuine owned conflict supports fresh-process `continue` in the original source, retaining resolution choices and isolated staged/unstaged input. Selected-range construction conflicts retain their detached owned checkout and original-commit checkpoint; resolve in its printed path and continue from the source. During this pause `continue --all` stages only that construction checkout. Before staging or advancing, continuation rechecks refs, protection, worktrees, ownership and forbidden repository/index Git environment overrides, including overrides aimed elsewhere. Noncontinuable failures report reached work and an executable guarded restoration path. Earlier amendments survive raw Git abort; no universal rollback is promised. Existing stored stacks and unrelated legacy continuation behavior remain compatible.

The existing MCP tools use the same installed CLI with literal arguments. `learn_an` describes the command; no new transport, tool or authorization rule is introduced. Final local Node/native and isolated installed npm receipts are recorded in [implementation verification](./docs/verification/absorb-implementation-2026-10-29.md). Those receipts are implementation acceptance, separate from historical Graphite comparison observations and from live service/release validation.
