# Bounded get/sync live-evidence audit

Scope: retained G01/G02, G11–G15, S11/S12, P11–P13 and D11 only. No C* cleanup case was read or adjudicated. The audit performed no remote action, CLI mutation, REA-session operation or user/global configuration access. It read local snapshots/captures, selected fixture Git objects and the exact frozen-after SQLite rows.

[Machine-readable audit](live-audit.json) retains capture/snapshot SHA-256 values, Evidence IDs, argv, terminal output, observed deltas and paired-input checks. There are **22 command observations**, including three initial native-unsubmitted observations; the normalized main set has **19 observations**. These are not feature-acceptance pass counts. Baseline synchronization captures are separate setup evidence.

## Paired conditions and evidence limits

Seven primary pairs have equal local head maps, parent relations, branch trees, checkout/status and working file hashes before execution. Their raw index hashes differ across tools; no cross-tool byte-identical index precondition is claimed. D11 is the explicit unequal-local-commit exception described above. Metadata storage formats and service synchronization history differ by product.

The normalized setup is supported by actual Graphite `get child --force --downstack --no-restack`, which reports syncing PR14 v2 from `0dfbd2d`, and actual Anthracite `get child`; subsequent before snapshots agree at `67a223e`. G11 then observes a normal remote FF to `df5b85e`. The real-gh shim directly execs installed gh with its credential HOME restored; it does not substitute API responses. No credentials or private-runtime contents were read by this audit.

Snapshot `refs` covers local heads and Anthracite metadata refs; it does not certify that every remote-tracking, temporary, cache, recovery or configuration byte was preserved. REA captures state before/after, not syscall traces; sampled process trees and inherited ambient environment retain their stated limitations. All reviewed captures report normal exit and no capture truncation, which does not erase those coverage boundaries.

[Independent frozen-after proof](live-audit-frozen-after.json) records the actual schema/rows and unchanged SQLite digest. [Read-only Git object proofs](live-audit-local-proofs.json) record FF ancestry, restack file content and local-only commit retention. No concrete contradiction was found for the bounded G11/S11/G14 conclusions. The qualifications above prevent broader conclusions than these fixtures support.
