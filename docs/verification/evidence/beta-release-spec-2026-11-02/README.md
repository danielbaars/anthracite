# Beta release specification evidence

This directory supports the specification dated 2 November 2026. It contains source observations and documentation validation, not results of the future release implementation.

- [Approved scope and test boundary](approved-boundary.json): English summary of the owner's approval, including the separately approved future live-beta boundary.
- [Source basis](source-basis.json): seven SHA-256-pinned source inputs from released main 0.6.5, with immutable GitHub URLs and bounded static observations.
- [Registry baseline](registry-baseline.json): read-only public npm observation of the existing stable package and dist-tags, with observation time and limitations.
- [Documentation validation](validation.json): template, numbered-story, source hash, link/anchor, JSON and changed-file-scope checks for this delivery.

The [basis report](../../beta-release-spec-2026-11-02.md) explains how the evidence supports the [specification](../../../specs/beta-release-channels.md). No credentials, private project data or raw user conversation are included.
