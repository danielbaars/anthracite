# Sync candidate evidence index

This directory curates English implementation evidence for [sync candidate verification](../sync-updates-implementation-2026-11-01.md). It contains no chat, human approval text, task STATE, user configuration, fixture repositories, dependencies or executable binaries. The unchanged slice author reports retain their original task-root paths as provenance; raw historical logs named inside them remain author receipts, not automatically bundled files or current-source results. [Report hashes](slice-report-sha256.json) verify the copied bytes.

The implementation baseline is merged get commit [`26c8b643`](https://github.com/danielbaars/anthracite/commit/26c8b64373e0c57bf2fd833a6a65bfeb827d8bfd). The table records final slice handoffs, not a sum of features or an assertion that every case ran at each final handoff. Repeated cohorts, Node/native executions, retries and independent confirmation probes never add case identities. Dry-run inventories enumerate names only; Mocha's generated passing counters in a dry run are not acceptance.
