Freeze-only changes on completed anchors remain allowed; new freezes on active/pending replay refuse. Opaque metadata stays unchanged and is never imported/normalized by recovery.

Configured repository/head-repository, number/URL/head name, exact terminal state, base and (when freshly snapshotted) remote head identity must still match.
