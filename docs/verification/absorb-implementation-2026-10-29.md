## Closed input-boundary gaps

Stable gitlink paths/pointers are checked against source HEAD/index and every construction/replay tree, including intermediate commits and range bases. Their commit object need not exist in the superproject store. An initialized dirty module retains nested tracked/untracked bytes, raw index and HEAD; recursive checkout is disabled only for absorb-owned Git. An absent module remains absent after checked removal of Git's verified-empty checkout stub with nonrecursive `rmdir`. Nested contents are never recursively removed or treated as blobs. Pointer/add/delete/type transitions or physical collisions refuse early with the affected path. Real `--all` staging can project deletion of an absent module; that transition refuses before real publication, while plain absorb supports unrelated staged text with the module absent.

Physical symlink targets are read as raw bytes. The existing retained string format accepts only exact UTF-8 round trips; invalid targets refuse before private staging or publication. Fingerprints and unchanged checks compare raw target bytes. Ordinary Unicode links retain staged and unstaged roles. This closes the observed replacement-decoding hazard without introducing a new link format.

Absorb and owned continuation share a repository/index environment refusal. Before ordinary continuation context handling, physical-source discovery detects the saved absorb role even when an override points at another Git directory. The standalone restoration template injects the same variable list and refuses before Git/filesystem mutation. Unrelated legacy continuation keeps its previous semantics.

The [development-cycle ledger](evidence/absorb-implementation-2026-10-29/development-cycles.json) preserves classifications and original receipt hashes without adding those executions to final counts. Actual new reds include successful foreign-index continuation, blanket unchanged-gitlink refusal and successful redirected manual restoration. The first new invalid-link test encountered a generic existing Git-record refusal after private projection; it is not claimed as an executed corruption red. The independent byte probe established the lossy read behavior. Additional controls exposed an absent-module preflight refusal and a later empty-stub restoration refusal before the bounded fix. One initial fixture used an unsupported `restack --stack` spelling; a development MCP protection expectation misunderstood a frozen ownership boundary. Those were test/setup corrections, not product bugs. Existing and passing-first controls are not described as invented reds.

## Reproduction and limits

Use Node 24.19.0 and the checked-in Yarn runtime to build the CLI, then run `tsc --noEmit` and uncached lint for the changed source/test files. Compile the native candidate with Bun 1.3.14 from `apps/cli/dist/src/index.js`. `scripts/test-cli.cjs node` and `scripts/test-cli.cjs native` use `TEST_FILTER='commands/absorb_.*_cli\.test\.js$'`; set `ANTHRACITE_TEST_BINARY` to the independently compiled absolute path for native. The selected legacy report identifies its six files and 16 exact executed cases. The npm build uses `scripts/build-npm-package.cjs`; `scripts/test-npm-package.cjs` installs its immutable tarball offline into a disposable prefix. The external numeric-zero-only retry narrows only that unchanged package check and requires local process observation outside the sandbox.

The retained [representative traces](evidence/absorb-implementation-2026-10-29/capture-selection.json) cover preview, environment refusal, genuine conflict/continuation, hook/manual restoration and installed MCP. Native binaries, tarballs, complete temporary repositories and exhaustive raw captures are intentionally omitted from the portable evidence; their hashes remain authoritative.

This is focused local implementation acceptance on macOS ARM64. It does not certify other platforms, arbitrary byte conversions, submodule update transitions, arbitrary user hook effects, live Graphite/GitHub services, universal rollback or automatic post-abort retry. No full repository suite/full CI matrix, Actions dispatch, live GitHub fixture, release/tag/asset publication, global installation or MCP client configuration ran. Root review, metadata approval and the one implementation PR remain separate delivery steps; this local verification does not close issues.
