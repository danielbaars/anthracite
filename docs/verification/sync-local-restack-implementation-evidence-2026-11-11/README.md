# Sync local history implementation evidence

Selected receipts for [the local verification record](../sync-local-restack-implementation-2026-11-11.md). Per-slice summaries distinguish original failures, code epochs and successful retries; do not add overlapping counts together. Their auxiliary local receipt paths are provenance rather than additional repository files.

The candidate and published recovery records are unchanged source copies from synthetic repositories. Package receipts refer to one isolated candidate, not a published version or the active user installation. `SHA256SUMS` verifies the unchanged selected copies and `provenance.json` records their original paths. Large native binaries, tarballs and temporary Git repositories are intentionally not committed.
