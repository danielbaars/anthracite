## Historical evidence and boundaries

`slice21`–`slice25` contain unchanged earlier reports and red/green receipts. They establish the incremental implementation history and are **not** counted again in the final 67. In particular, #21's initial missing-option red was observed in its tool transcript rather than retained as a raw report. #22 corrected a test setup that attempted to freeze trunk. #23's speculative empty-subtree expectation was corrected after measurement; that exploratory failed expectation is not a product defect. Historical TDD reds are not current acceptance failures. The initial #25 build lacked ignored workspace dependency links; adding those links resolved the environment without dependency or toolchain changes.

The [retained-file manifest](evidence/split-by-file-implementation-2026-10-28/manifest.json) hashes only copied/generated evidence files. Historical nested manifests remain unchanged receipts and may mention omitted host-local binaries; the outer manifest defines the retained subset. Native identity is metadata only. Original Graphite demonstration/specification observations remain separate in the [specification research](../research/split-by-file-spec-research-2026-10-28.md); these implementation results do not claim complete Graphite parity.

Real hooks execute in owned detached temporary work and can lack ignored project tooling. Failures preserve reported work/locks and may require manual recovery. File mode refuses repository/index Git environment redirections early. A completed extraction is not undone by aborting a later rebase. Other operating systems, arbitrary external hook effects and general transactional rollback are outside this bounded acceptance.

History is linear since product baseline `3923b1088b29f02ce9d9e2d8da9fb52339889915`, and `LICENSE`/`CREDITS.md` are unchanged. Delivery remains one implementation PR for #20 and #21–#25 after independent review and metadata approval; this report does not publish a PR or close issues. No full repository suite/full CI matrix, Actions dispatch, live GitHub fixture, release/assets/tag, global install or client registration ran. Documentation-only commits after the recorded candidate must preserve its product/build identities.
