# Credits and provenance

Anthracite is a modified fork of [Charcoal](https://github.com/danerwilliams/charcoal), maintained originally by [Dane Williams](https://github.com/danerwilliams). Charcoal derives from the formerly open-source [Graphite CLI](https://github.com/withgraphite/graphite-cli), created by the Graphite team and its contributors. The complete inherited Git history preserves the original authors and their contributions.

Anthracite's additional implementation, tests and release setup were developed in October 2026. The first locally used version was 0.1.0; 0.1.1 establishes the standalone repository.

The original GNU Affero General Public License version 3 is retained unchanged in [LICENSE](LICENSE). Package metadata identifies that license as `AGPL-3.0-only`. Existing copyright and attribution notices remain intact. Third-party dependencies retain their own licenses and ownership.

The upstream remote remains available for tracking the source project's changes. Existing research links and historical commit messages refer to the repositories where that work originally happened; those references have not been rewritten.
