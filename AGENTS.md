# Repository instructions

- Write source comments, documentation, commit messages, issue text, pull-request metadata and release notes in English. Conversation with the user may use their preferred language. This repository's English publication rule takes precedence over personal preferences for other repositories.
- Before changing build, test, installation or release tooling, read [CONTRIBUTING.md](CONTRIBUTING.md).
- Preserve the inherited license, copyright notices and [credits](CREDITS.md). Before changing stored metadata or legacy names, read the compatibility boundaries in [docs/installation.md](docs/installation.md) and verify existing stacks and interrupted operations can still be used.
